# EE Rectifiers (`ee_rectifier`)

Аддон сборки для Create Electro Energetics: выпрямители одним блоком вместо диодного моста.
Общие правила разработки аддонов — [docs/addons.md](../../docs/addons.md); для игроков — сайт, «Справочник → Аддоны».

| Блок | Клеммы (номера контактов) | Внутри | Рецепт (верстак) |
| --- | --- | --- | --- |
| Трёхфазный выпрямитель `ee_rectifier:three_phase_rectifier` | медные 0–2 — фазы, красная 3 — «+», синяя 4 — «−» | нагрузка треугольником + источник постоянного (1.1) | `CDC / DPD / DDD`: C — опорный изолятор EE, D — диод EE, P — `#c:plates/iron` |
| Однофазный выпрямитель `ee_rectifier:single_phase_rectifier` | медные 0 — фаза, 1 — нейтраль (порядок не важен), красная 2 — «+», синяя 3 — «−» | нагрузка + источник постоянного (1.1) | `CDC / DPD / _D_` |

**С 1.1 диодов внутри нет** (версия 1.0 была мостом из `DiodeProperties` и на генераторе при microTicks = 1
скакала — диод EE линеаризуется по прошлому расчёту). Теперь `RectifierDevice`: вход — резисторы между входами
(трёхфазный — треугольником), выход — `energyLimitedSource` с запасом энергии. Напряжение выхода — среднее идеального
моста: трёхфазный (3/π)·U_лин, U_лин² = ⅔(u_ab² + u_bc² + u_ca²) — видно в любой момент, от угла ротора не зависит;
однофазный (2/π)·A, A — по среднему квадрату за 40 тиков (на оборотах, кратных 64, ошибается — одна точка синусоиды).
Сопротивление входа — как у настоящего моста: нагрузка выхода, пересчитанная на сеть (π²/6·R треугольником, π²/8 у
однофазного), ± 25 % на заполнение запаса; меняется не быстрее чем в 1,25 раза за тик. Первый вариант 1.1 тянул вход
«под мощность» (постоянная мощность) — под перегрузкой раскачивал генератор, от этого отказались. Энергия сходится
(InputPower = OutputPower в `/cee device_data`).

Ставится и поворачивается как преобразователь EE (шесть сторон, крен ключом), бывает в воде и масле. Нужен на
сервере и у всех игроков. NeoForge 21.1.219+, Create 6.0.10, Electro Energetics 1.1.2+.

## Устройство

- `Layout` — раскладка клемм и подписи; `RectifierBlock` — блок (`DirectionalRolledDeviceBlock` EE, контакты через
  `NodeConfigurator`); `RectifierDevice` — мост из `DiodeProperties`; `EeRectifier` — регистрация блоков, предметов и
  типов устройств EE, вкладка творческого режима EE.
- `art/gen_assets.py` — текстуры, модели (обычная и с креном), блокстейты; координаты клемм те же, что в `Layout`.
  `art/iso.py` — объёмные иконки для сайта (свой растеризатор: модель под поворотом gui, как в инвентаре).

## Сборка и проверка

```bash
./libs.sh          # Create и EE из ../../mods для компиляции (один раз и при обновлении сборки)
./release.sh       # ресурсы → сборка → проверка клемм → jar сюда и в ../../public/addons
./test-server.sh   # сервер разработки: загрузка, установка, электрика (минута-две)
```

`JAVA_HOME` по умолчанию — `~/.gradle/local-tools/jdk21` (см. docs/addons.md, «Среда»).

## Что проверено (2026-10-14)

- Собирается на NeoForge 21.1.219; загружается на сервере разработки вместе с Create 6.0.10 и EE 1.1.2.
- `check-nodes.sh`: клеммы моделей совпадают с точками крепления проводов во всех 12 положениях обоих блоков (108 из
  108) — настоящим `NodeConfigurator` EE и `BlockModelRotation` Minecraft; на испорченных данных проверка падает.
- `test-server.sh`: блоки ставятся в разных положениях, EE создаёт устройства (6 и 4 диода), при сломе удаляет.
  Тестовый мод `src/devtest` собирает цепи с проводами через API EE: от творческих батарей переменного тока 100 В
  (фазы 0°/120°/240°) на нагреватель 45 Ом — трёхфазный 125 В, однофазный 79 В на выходе, положительная полярность;
  открыты нужные диоды (падение 8,6–16,4 В — свойство диода EE, см. выше).

Тот же тестовый мод проверяет генератор EE для справочника (`/rectest gen|genload|genshortwire|genreport`, файл
`src/devtest/.../Generator.java`): `./test-server.sh 'rectest gen 64' 'sleep 4' 'rectest genreport'`.

**Версия 1.0 (с диодами) с настоящим трёхфазным генератором** (`/rectest ac <об/мин>`, `acrpm`, `acwatch <тиков>`, `acreport`;
`MICROTICKS=N ./test-server.sh …` — настройка EE `simulation.microTicks`): блоки ведут себя ровно как мост из шести
отдельных диодов EE, а сами диоды EE при microTicks = 1 успевают за фазой только до ~4 об/мин — выше выход скачет. При
microTicks = 32 ровно до 100 об/мин, на 256 — ±4 %. Подробности — `docs/plans/electricity.md`, «Диоды EE и переменный ток».

**Версия 1.1** (те же команды): трёхфазный ровно на 1–256 об/мин при microTicks = 1 (16 — 150 В, 256 — 2329 В),
вход = выход по мощности, остановка генератора — ноль, двойная перегрузка — проседает до ~99 В устойчиво, короткое
замыкание — сгорают провода. Однофазный на оборотах, кратных 64, ошибается.

Не проверено: в игре с игроком (вид, установка катушкой, рецепт в JEI/EMI).
