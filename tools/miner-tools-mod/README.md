# Miner Tools — снаряжение шахтёра (`miner_tools`)

Аддон сборки с предметами для шахтёров: пояс шахтёра (1.0.0) и каска шахтёра с фонарём (1.1.0).

## Пояс шахтёра (`miner_tools:miner_belt`)

Пока пояс надет (слот Curios «пояс») или лежит в инвентаре, игрок не подбирает предметы из его фильтра.

- **ПКМ** поясом в руке — окно фильтра: 9 ячеек-образцов. Клик предметом по ячейке (или Shift+клик по предмету в
  инвентаре) — его копия становится образцом, предмет остаётся у игрока; клик пустой рукой — убрать образец.
- **Shift+ПКМ** — включить/выключить (сообщение над хотбаром). Работающий пояс с фильтром блестит.
- **«Все породы»** (по умолчанию да): образец означает все породы и почвы. Склеиваются id, отличающиеся только
  последней частью, если обе части — названия пород или почв (их мод собирает при загрузке из id `*:rock/loose/<порода>`
  и `*:dirt/<почва>`): `tfc:rock/gravel/granite` ~ `tfc:rock/gravel/basalt`, но не `tfc:ore/poor_hematite` ~
  `tfc:ore/rich_hematite` и не слитки. Плюс общие теги `c:stones/loose` (замшелые камешки) и `c:gravels`.
- Рецепт (только с TFC): кожа + джутовая сетка + кожа в ряд.

Устройство:
- `PickupFilter` — `ItemEntityPickupEvent.Pre` (NeoForge спрашивает его каждый тик, пока игрок касается предмета):
  `setCanPickup(FALSE)`. Улучшение «Подбор» Sophisticated Backpacks (3.25.74, по байткоду) забирает предмет в рюкзак,
  не глядя на этот флаг, но пропускает предметы с `pickupDelay > 0` — поэтому на HIGHEST задержка 1 тик, на LOWEST
  снова 0.
- Настройки — компоненты предмета: `miner_tools:filter` (образцы), `enabled`, `any_variant`.
- Окно — `BeltMenu`: ячейки-призраки (`mayPlace`/`mayPickup` = false, всё через `clicked`), ячейка с поясом заблокирована
  (и обмен цифрой/F). Кнопки — `clickMenuButton`. Экран — `client/BeltScreen` (фон сундука на 1 ряд).
- Curios: тег `curios:belt` + `data/miner_tools/curios/entities/player_belt.json` — в сборке слот «пояс» игроку
  никто не включал (есть head, charm, back). Поиск надетого — `findCurios(Predicate)`: `findCurios(Item)` кеширует
  ответ на весь тик (видно на сервере разработки).

## Каска шахтёра (`miner_tools:miner_helmet`, с 1.1.0)

Стальной шлем с аккумулятором и электрическим фонарём. Носится в слоте головы или в слоте Curios «голова» (его игроку
даёт Create — для очков инженера; так каску можно носить под другим шлемом, но тогда её модели не видно).

- **Заряд** — 100 000 FE (как у низковольтного конденсатора IE), принимает до 1 000 FE/т. Заряжается в зарядной
  станции IE, надетым ранцем питания IE и любым зарядником FE; отдать заряд нельзя. Полоска заряда — над полоской
  прочности, заряд и состояние фонаря — в подсказке.
- **Фонарь**: Shift+ПКМ каской или клавиша «Фонарь каски» (H, категория «Снаряжение шахтёра») для надетой. Пока
  включён и есть заряд — 2 FE/т (~40 минут на полный заряд, настройка `lampCost`) и свет 14 вокруг игрока. Свет —
  LambDynamicLights (клиентский мод сборки): он светит предметами в слотах брони и Curios по описанию
  `assets/miner_tools/dynamiclights/item/miner_helmet.json`, где условие — компонент `miner_tools:lit`. Этот компонент
  ставит сервер, пока каска надета, фонарь включён и есть заряд; снятой, выпавшей, надетой на стойку — снимает.
  Свет только для глаз: мобов не отпугивает, блоков не ставит. Под водой светит (электрический).
- **Защита**: урон из тега `miner_tools:cushioned_by_helmet` (= `#minecraft:damages_helmet`: наковальня, падающий
  блок, сталактит; обвалы TFC — тот же `minecraft:falling_block`, по байткоду `TFCFallingBlockEntity`) снижается на
  50% (`fallingBlockReduction`) в `LivingIncomingDamageEvent` — до обычных 25% за любой шлем и брони. Броня и
  прочность — как у стального шлема TFC (2, прочность брони 1, 440), сопротивление TFC — как у стальной брони
  (`data/miner_tools/tfc/item_damage_resistance`). Работает и без заряда.
- **Рецепт** (с TFC и IE): `PLP / WHW / RCR` — P стальная пластина, L электрический фонарь IE, W шерстяная ткань, H
  стальной шлем TFC, R медный провод, C низковольтный конденсатор IE.

Устройство: `helmet/Helmet` — регистрация (свои DeferredRegister, вызывается из `MinerTools`), компоненты `energy`,
`lamp_on`, `lit`, способность FE (`ComponentEnergyStorage`, как у щита IE), настройки сервера
`miner_tools-helmet-server.toml`; `HelmetEvents` — тик игрока (расход раз в 20 тиков: каждое изменение компонента —
пакет снаряжения всем рядом), выключатель, урон; `client/` — модель GeckoLib, клавиша, полоска заряда, иконка с
горящим фонарём (свойство `miner_tools:lit`).

Модель — из мода [Mining Helmet](https://github.com/CysticTurtle85/Mining-Helmet) (CysticTurtle85, MIT;
`art/mining-helmet/LICENSE`, в jar — `LICENSE-mining-helmet.txt`): `geo/miner_helmet.geo.json` без изменений, текстура
перекрашена `art/gen_helmet.py` по костям модели (исходник серый — мод красил ремешок на лету), иконка нарисована заново.

## Сборка и проверка

```bash
./libs.sh          # Curios и GeckoLib из mods/ сборки (в worktree — из основной копии)
./test-server.sh   # сервер разработки (+ IE) + /belttest и /helmettest (src/devtest), печатает OK/FAIL; PORT=… — свой порт
./release.sh       # jar сюда и в public/addons + иконка для сайта
```

Проверено на сервере разработки: подбор с поясом в инвентаре и в Curios, выключение, правило «все породы» (на своих
предметах с id как у TFC), окно фильтра без клиента (`BeltMenu` напрямую). **Не проверено:** в игре с игроком, клиентское
окно, рецепт (на сервере разработки нет TFC), с настоящим рюкзаком Sophisticated Backpacks.

Каска — проверено на сервере разработки (`/helmettest`, 28 проверок): способность FE (ёмкость, приём 1000 за раз,
отдать нельзя); зарядная станция IE заряжает каску до 100 000 FE; расход 2 FE/т, свет только пока включён и заряжен,
выключатель, разряд; снятая, выпавшая каска не светит; слот Curios «голова»; описание LambDynamicLights разобрано тем же
`ItemPredicate` Minecraft (горящая подходит, негорящая — нет); урон жителям: падающий блок и наковальня 10 → железный шлем
7,50, каска 3,75; падение 10 → 10 и 10; настоящие наковальни: −10,33 и −5,17. **Не проверено:** в игре с клиентом
(модель GeckoLib, свет LambDynamicLights, клавиша, полоска заряда), рецепт и сопротивление TFC (на сервере разработки
нет TFC), ранец питания IE.
