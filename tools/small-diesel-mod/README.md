# Small Diesel (`small_diesel`)

Аддон сборки к Create Diesel Generators (CDG): малые дизели. Общие правила разработки аддонов —
[docs/addons.md](../../docs/addons.md); для игроков — сайт, страница «Аддоны».

| Блок | Что делает | Рецепт |
| --- | --- | --- |
| Малый дизельный двигатель `small_diesel_engine` | Вращение Create: обороты обычного двигателя CDG на этом топливе, мощность — четверть (дизель — 1 536 SU на 96 об/мин); вал — из лицевой грани (FACING, как у творческого мотора), топливо — трубой с других граней или ведром, бак 1 000 мБ | `PTP / FES / PPP`: P — `#c:plates/iron`, T — жидкостный бак Create, F — огниво, E — поршень двигателя CDG, S — вал |
| Малый дизельный генератор `small_diesel_generator` (только с Electro Energetics) | Постоянный ток EE 100 В, до 1,5 кВт; клеммы в коробке на генераторе установки: красная 0 — «+», синяя 1 — «−» (высота 14); топливо — с любой грани, бак 1 000 мБ | `CMC / WEW / PPP`: C — опорный изолятор EE, M — электромагнитный блок EE, W — катушка медного провода EE, E — малый двигатель |

Нужен на сервере и у всех игроков. NeoForge 21.1.219+, Create 6.0.10, CDG 1.3.8; Electro Energetics 1.1.2+ —
необязательно (без него нет генератора, рецепт и добыча генератора — с условием `neoforge:mod_loaded`).

## Устройство

- `Fuel` — топливо из реестра CDG `createdieselgenerators:fuel_type` (данные CDG, датапак может поменять), свойства
  обычного двигателя (`normal`). У CDG двигатель держит `strength` SU на `speed` об/мин и сжигает 1 мБ за 1 / `burn_rate`
  тиков (по байткоду `DieselEngineBlockEntity.tick`, CDG 1.3.8), значит 1 мБ = `strength / burn_rate` SU·тик. Дизель —
  122 880. Топлива сборки: дизель, бензин, биодизель, этанол, растительное масло (`#c:plantoil`, с маслами TFC);
  KubeJS их не трогает.
- `EngineBlockEntity` (`GeneratingKineticBlockEntity`): скорость — `speed` топлива, мощность — `SHARE` (¼) ×
  `strength`. Расход: за тик — работа «загрузка сети × мощность», загрузка = `stress / capacity` (поля
  `KineticBlockEntity`, Create раздаёт их всем блокам сети). Оплаченная работа копится в `credit`; не хватает — сжечь 1 мБ.
  Бак пуст и `credit` кончился — скорость 0. Без нагрузки не жжёт (у CDG двигатель жжёт всегда).
- `electric/` — только при EE (класс `Electric` грузится после `ModList.isLoaded`). `GeneratorDevice` — источник с
  запасом, как щёточный узел EE (`GeneratingDevice` 1.1.2: `energyLimitedSource`, запас ≤ 10 тиков мощности), но в
  запас идёт только сожжённое топливо: приток (`pool`) кладёт блок-сущность (1 мБ = `strength / burn_rate` × 0,75 Вт·тик —
  КПД как у связки «двигатель + компактный генератор EE Extras», 1 SU ≈ 1 Вт как у генератора EE), устройство берёт из
  него не больше 1,5 кВт за тик. Нагрев — формулы вариака EE (как у выпрямителей EE Extras), номинал 1,2 кВт: на полной
  мощности (125 %) дымит, не сгорает. Клеммы — `Terminals` (без классов блоков — для `art/CheckNodes.java`).
- `EngineClient` — вращающийся полувал из лицевой грани (как у творческого мотора Create). Звука нет.
- `art/gen_assets.py` — текстуры, модели, блокстейты; `check-nodes.sh` — клеммы генератора = точки проводов EE во всех
  положениях.

## Сборка и проверка

```bash
./libs.sh          # Create, CDG и EE из jar сборки (кеш снимка, npm run pack:fetch) для компиляции
./release.sh       # ресурсы → сборка → проверка клемм → jar и иконки (icons/) сюда; на сайт — сборкой сайта
./test-server.sh   # сервер разработки: двигатели под нагрузкой, генератор, вода в бак (~2 мин)
NO_EE=1 ./test-server.sh 'setblock 0 -60 0 small_diesel:small_diesel_engine[facing=up]'   # без EE
```

Команды проверочного мода (`src/devtest`): `/sdtest engines` (четыре двигателя: вентилятор; коробка передач и три
вентилятора; вентилятор и 2 мБ в баке; без нагрузки), `/sdtest generator <нагревателей>`, `/sdtest heaters <n>`,
`/sdtest mark`, `/sdtest report` (расход за время с отметки против расчёта), `/sdtest water`.

## Что проверено

**1.0.1 (2026-10-22)** — только вид: двигатель — горизонтальный одноцилиндровый дизель (радиатор на торце цилиндра,
бак, фильтр, глушитель, маховик у вала, салазки); генератор — дизель-генераторная установка на раме (дизель, генератор,
клеммная коробка). Модели — `art/gen_assets.py` на `art/kit.py`. Клеммы: 24 из 24, `resources_check` без ошибок;
механика и числа не менялись. В игре не проверялось.

**1.0.0 (2026-10-22), сервер разработки** (NeoForge 21.1.219, Create 6.0.10, CDG 1.3.8, EE 1.1.2), `./test-server.sh`:

- Двигатель на дизеле — 96 об/мин, 1 536 SU. Вентилятор (загрузка 0,125) и коробка с тремя вентиляторами (0,375):
  работа по сожжённому топливу = загрузка × мощность × тики (268 800 и 806 400 SU·тик за 1 400 тиков — ровно). Без
  нагрузки за 70 с — 0 мБ. С 2 мБ в баке под нагрузкой — остановился, когда они кончились. Воду бак не принимает.
- Генератор: 4 нагревателя — 98,5 В, 862 Вт (= U²/R); 8 — упор в 1 500 Вт, 91,9 В. Сожжено × 92 160 = отдано
  (517 489 = 517 489; 902 130 против 900 000 — запас на отметке). Температура на 125 % — 28 800 за 30 с.
- Без EE: аддон грузится, двигатель ставится, блока генератора нет. Клеммы: 24 из 24.

Не проверено: в игре с игроком (вид, вращение вала, ведро рукой, трубы Create, JEI/EMI) — клиент здесь не
запускается; перегрузка сети вращения, несколько двигателей в сети; топлива кроме дизеля — только по данным CDG.
