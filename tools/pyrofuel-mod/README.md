# TFC Pyrofuel

Промышленное топливо вместо торта всполоха: пирококсовый брикет для обычной горелки Create и жидкий пирогель для
жидкостной горелки Create Diesel Generators. Устанавливается на сервер и всем игрокам.

## Производство

1. 2 коксовые пыли IE + незераковый порошок Create → 1 пирококсовая смесь (смеситель).
2. Твёрдая ветка: смесь + 250 мВ креозота → пропитанная пиромасса → прессование в чаше → сырой брикет →
   смеситель с обычным нагревом → пирококсовый брикет.
3. Жидкая ветка: графитовый порошок TFC + флюс TFC → 4 стабилизирующие присадки. Смесь + присадка + 250 мВ дизеля CDG
   → 250 мВ сырого пирогеля → смеситель с обычным нагревом → 250 мВ пирогеля.

Кокс даёт жар, незераковый порошок сохраняет нижний огонь. Креозот связывает твёрдый заряд; минеральная присадка
стабилизирует жидкую взвесь. Это игровой лор, не описание реального топлива.

## Применение

- Брикет даёт обычной горелке всполоха 3200 тиков перегрева: 160 секунд при 20 TPS.
- Пирогель подаётся трубой в штатную горелку CDG с любой стороны, кроме верхней. Её буфер — 100 мВ.
  Откройте клапан вращением вала: перегрев начинается выше 80% открытия. На полном открытии расход — 1 мВ за 10 тиков,
  то есть 250 мВ хватает на 125 секунд при 20 TPS. При пустом баке нагрев прекращается.
- В обычную горелку всполоха жидкость напрямую не подаётся: для неё используется брикет.
- Баки, насосы и жидкостные трубы работают через стандартную способность NeoForge. Ведро — 1000 мВ.
  Обе жидкости нельзя разлить источником в мир. Осадка, засорения, взрывов и нагрева баков нет.
- Сырой пирогель не является топливом. Пирогель не даёт мощности дизельным двигателям.
- Старые торты продолжают гореть и обмениваются в сетке крафта 1:1 на брикеты; рецепты основы и торта выключены.

## Основания по коду

Create 6.0.10: `BlazeBurnerBlockEntity.tryUpdateFuel` читает карту `superheated_blaze_burner_fuels`.
CDG 1.3.8: `BurnerBlockEntity.tick`, `calculateHeatLevel`, `registerCapabilities`; `FuelType.CODEC` — коэффициент
`burner_multiplier`, порог перегрева 1,8. При коэффициенте 1 нагрев = 1 + открытие клапана.
NeoForge 21.1.251: `BaseFlowingFluid`, `BucketItem.emptyContents` и стандартные жидкостные способности.
Миксины не нужны. Текстуры и локализация генерируются из `art/`.

## Сборка и проверка

JDK 21, `./libs.sh`, `./gradlew build`, `./test-server.sh`.
Порты проверки: RCON 25604, Minecraft 25605.
`KEEP=1 ./test-server.sh 'pyrotest persist'` проверяет сохранение бака при перезапуске.
Проверочный мод находится в `src/devtest` и в выпускаемый jar не попадает.

В игре не проверялось: клиентское отображение, автоматизация полной производственной линии и поведение в полном
составе сборки. Подробные фактические результаты проверки — на странице аддона и в задаче №104.

## Результат проверки 27.10.2026

На сервере разработки прошли `pyrotest persist`, `buckets`, `setup`, `report`, `empty`, `stopped`:
сохранено 1900 мВ после перезапуска; ведро ↔ бак без потерь; все восемь рецептов загружены, два старых выключены;
брикет принят как SPECIAL; пирогель дал heat=2,0, через 8 секунд осталось 84 из 100 мВ;
настоящие насос и трубы подают топливо (источник вращения стенда задаёт насосу постоянные 64 об/мин);
двигатель не получает мощности, расчёт конечный; без топлива нагрев выключается.
Проверка обнаружила ошибки при первом запуске, затем прошла после исправления способности вёдер и стенда.
Четыре старые ошибки рецептов CDG/IE вынесены в dev #118, к аддону не относятся.
