# TP Trace (`tp_trace`) — диагностика телепортов

Временный аддон для поиска, кто переносит игрока. Пишет в лог (`logs/latest.log`, строки `[tp-trace]`):

- **скачок** — позиция игрока сменилась больше чем на 4 блока за раз, на сервере или в игре (`Entity.setPosRaw`),
  со стеком вызовов: по кадрам `handler$…$<мод>$…` и классам видно, какой мод или команда это сделали;
- **сервер шлёт телепорт #N** — `ServerGamePacketListenerImpl.teleport` (номер, куда, стек);
- **игра получила телепорт #N** (только клиент) и **игра подтвердила телепорт #N; сервер ждёт #M** — если номера не
  совпадают, сервер не принимает движение и раз в секунду повторяет телепорт.

Не больше 10 строк в секунду. Не для сборки: ставить только тому, у кого ищем ошибку, и убрать после
(перед `tfc publish` — обязательно, иначе уйдёт всем).

Сборка — `./build.sh` (как у rw-host-fix: Minecraft+NeoForge из среды ee-rectifier-mod). Проверка — сервер разработки
rw-host-fix: `EXTRA_MODS="../tp-trace-mod/tp-trace-1.0.0.jar" ../rw-host-fix-mod/test-server.sh 'rwtest portal -297 -6200'`
— в логе скачок тестового игрока со стеком до команды `/rwtest`.

Повод (2026-10-21): в аду игрока молча возвращает в точку прибытия (портала там нет), `/tp` не помогает; в логах
игры об этом ничего, и по коду модов виновник не найден.
