# Host Tools (`host_tools`)

Удобства для «мира хоста» (одиночный мир, открытый для сети). Только ванильный код Minecraft 1.21.1 + NeoForge,
от модов сборки не зависит.

## Команды

- `/host` — открыть мир для сети на порте из настроек (57016). `/host <порт>` — на этом порте (1024–65535).
- `/host random` — случайные порты из `randomFrom`–`randomTo` (20000–45000), до `randomAttempts` (30) попыток.
- `/host stop` — закрыть мир для сети без перезахода; `/host status` — открыт ли и на каком порте.
- `/ping [игроки]` — пинг игроков в мс, цветом по порогам палочек таба (150 / 300 / 600 / 1000 мс).

`/host` может только хост (владелец мира) или оператор (уровень 4, например консоль); `/ping` — все.

Настройки — `config/host_tools-common.toml` у хоста: порт, диапазон и число попыток для random, режим игры и читы
для гостей (по умолчанию — как в мире, как в окне «Открыть для сети»), как часто рассылать пинг для таба.

## Как устроено (сверено по коду Minecraft/NeoForge 21.1.251)

- **Открытие.** То же, что окно «Открыть для сети» и `/publish`: `MinecraftServer.publishServer(режим, читы, порт)`.
  Перед этим порт проверяется `ServerSocket` на тот же адрес (все адреса), что берёт Netty в
  `ServerConnectionListener.startTcpServerListener`, — так видна причина отказа («Address already in use» и т. п.).
  Попытки идут по одной отдельными задачами сервера (`TickTask`): игра не висит, между попытками в строке над
  хотбаром виден прогресс. Не по тикам: мир хоста, ещё не открытый для сети, на паузе (меню, окно не в фокусе) не
  тикает — первая версия из-за этого ждала, пока хост закроет меню.
- **Закрытие** (обратное `publishServer`, в Minecraft его нет): гости отключаются (`connection.disconnect`), из
  `ServerConnectionListener.channels` закрывается и убирается TCP-канал (канал в памяти — сам хост — остаётся),
  соединения, которые ещё не вошли, закрываются; миксин на `IntegratedServer` ставит `publishedPort = -1`, снимает
  режим игры гостей и останавливает LAN-объявление (`LanServerPinger`) — как `stopServer`/`halt`. После этого мир снова
  можно открыть любым способом. Кнопка «Закрыть для сети» встаёт в меню паузы на место «Жалоб на игроков» (Minecraft
  показывает её вместо «Открыть для сети», когда мир открыт).
- **Пинг.** Число — `ServerCommonPacketListenerImpl.latency()`. Minecraft замеряет его keep-alive раз в 15 с и
  сглаживает (¾ старого + ¼ нового), но **Packet Fixer** (в сборке) подменяет эти 15 с своим `timeout` — 120 с по
  умолчанию (`@ModifyConstant 15000L` в `keepConnectionAlive`): у гостя пинг первые 2 минуты 0 и до настоящего
  доходит минут за десять (1.0.0 из-за этого показывала 0 и пустой таб). С 1.0.1 аддон мерит сам (`PingProbe`):
  раз в `probeTicks` (40) шлёт `ClientboundPingPacket` с меткой в id, ванильный клиент отвечает `ServerboundPongPacket`
  (`ClientCommonPacketListenerImpl.handlePing`, мод у гостя не нужен), ответ ловит миксин на пустой
  `handlePong` (поток сети, без ожидания тика сервера); новое значение = (старое + замер) / 2, пишется в то же поле.
  Клиент отвечает на своём главном потоке — в замер входит до одного кадра гостя, как и у keep-alive. Рассылка для
  таба — раз в `broadcastTicks` (40) вместо 600. У хоста пинг 0 (соединение в памяти) — в табе у него цифры нет.
- **Таб.** Миксин на `PlayerTabOverlay.render`: к ширине колонки (имя + счёт + 13 под палочки, константа 13 одна на
  метод) добавляется ширина цифр, вызов `renderPingIcon` обёрнут (`@WrapOperation`) — после палочек рисуется текст.
  Watut перенаправляет тот же вызов (`@Redirect`, у «отошедших» — свой значок); вместе с ним проверено.

## Проверка

- `./test-client.sh` — клиент разработки (окно откроется и закроется само): проверочный мод создаёт плоский мир и
  проверяет занятый порт (ошибка с причиной), `/host`, ответ порта на запрос списка серверов, повторный `/host`,
  `/host status`, `/ping`, таб (скриншоты `run/screenshots/httest-*.png`), `/host stop` с незашедшим соединением,
  `/host random` при занятых портах, кнопку в меню паузы, порт в окне «Открыть для сети», открытие после закрытий.
  `/host` сразу с меню паузы (сервер на паузе), свой замер пинга (в проверке мерится и хост:
  `-Dhost_tools.probeOwner=true`). `EXTRA_MODS="<jar> …"` — то же с модами сборки (Watut + Coroutil, Packet Fixer).
- `./test-server.sh` — выделенный сервер: аддон грузится без клиентских миксинов, `/host` отказывает, `/ping` работает.

Не проверено: настоящий гость по сети (вход, отключение при `/host stop`, пинг гостя), Windows (у хоста) — порты,
закрытые системой, там могут называться иначе.
