# План: раздел «Еда» — сборные блюда

Статус: **первая часть сделана**. Во вкладке «Еда» два вида: «Продукты» (плоская таблица по `data/*/tfc/food`) и
«Сборные блюда» (`?tab=food&sub=meals`).

## Сделано

- `scripts/mods/meals.mjs` → `public/meals.json`.
- Семейства из рецептов с модификатором `tfc:meal` (16 семейств, 26 блюд): основа, слоты начинок с количеством
  «от и до» по всем вариантам рецепта, инструмент, значения самого блюда и доли от ингредиентов. Блюда, отличающиеся
  только видом основы (шесть хлебов), сливаются в одно семейство.
- Формула `tfc:meal` (проверено по `MealModifier.apply`): значения блюда + по каждому ингредиенту-еде
  `его значение × множитель доли × количество`; долю выбирает первый подходящий `ingredient`, доля без него — для
  всех остальных. Сытость и порча — всегда из блюда. Значения множителей по умолчанию (1) — из кодека `MealPortion`.
- Суп (`SoupPotRecipe`) и салат (`SaladContainer`) — из кода: класс, создающий еду с вычисленной питательностью
  (`setFoodForDynamicItemOnCreate` + `new FoodData`), коэффициент, вода и насыщение блюда, число порций супа.
- «Дальше»: рецепты с `copy_dynamic_food` (сырая пицца → пицца из печи).
- Состав тегов начинок — на сайте из `tags.json` с правками KubeJS; поиск по продукту находит блюда, куда он годится.
- KubeJS текущей сборки ни один из 577 рецептов блюд не удаляет (проверено `recipeFilter.ts`), поэтому отсев
  удалённых пока не встроен.

## Осталось

- Блюда Kaleidoscope (`ktfcc`: `dishes`, `soups`) — еда считается своим кодом, не по образцу TFC; скрипт их находит
  и пишет предупреждение, формула не разобрана.
- Farmer's Delight (`farmersdelight:cooking`), Cuisine Delight, Firmalife (джемы, `stinky_soup`, `bowl_pot`) — свои
  типы рецептов без `tfc:meal`.
- Отсев рецептов, удалённых KubeJS, — встроить, когда появится первое удаление (сейчас их нет).
- Калькулятор «положил вот это — получил вот столько».
- Салат: сколько салатов делается за раз и минимальное число продуктов — не дочитано.
- Связи: ботаника («идёт в сэндвичи, супы» вместо числа), фильтр по семейству в рецептах, столбец «в какие блюда
  годится» у продукта.

## Что такое сборное блюдо

Рецепт, в который ингредиенты подставляются через тег: сэндвич = любой хлеб + любые начинки, суп = любые овощи,
салат, пицца, джем, блюда Farmer's Delight и Kaleidoscope. Один такой рецепт «использует» почти всю еду сборки:
у арахиса в ботанике было 156 рецептов, из них свой продукт — три.

Как отличить скриптом (уже применяется в `scripts/mods/botany.mjs`): предмет на выходе считается сборным, если он
получается из пяти и более разных растений. Для раздела еды нужен более точный признак — см. ниже.

## Что показывать

| Блок | Содержимое | Откуда |
| --- | --- | --- |
| Семейство блюда | «Сэндвич», «Суп», «Салат», «Пицца», «Джем»… | группировка рецептов по типу и общему шаблону id (`*_bread_sandwich`, `*_soup`) |
| Основа | все варианты хлеба (ячменный, кукурузный, овсяный, рисовый, ржаной, пшеничный) | вход рецепта, заданный тегом основы |
| Начинки | что можно класть и сколько слотов | теги ингредиентов рецепта (`#tfc:foods/usable_in_sandwich` и подобные) + состав тегов из `public/tags.json` |
| Что получится | сытость и питательные группы зависят от начинок | модификаторы результата в рецепте (`tfc:meal`, `copy_food` и т. п.) — разобрать формулу в коде |
| Посуда и способ | миска, кастрюля, нож, печь | тип рецепта и требуемые предметы |

## Что разобрать

1. Типы рецептов сборных блюд в каталоге (`public/recipes.json`): какие поля задают основу, начинки, число слотов.
2. Формулу питательности результата: модификаторы `ItemStackModifier` у TFC (класс `MealModifier` и соседние) —
   через `scripts/mods/classfile.mjs`, как в ботанике.
3. Составы тегов начинок — уже есть в `public/tags.json`; учесть правки KubeJS.
4. Блюда других модов (Farmer's Delight, Kaleidoscope Cookery, Firmalife): у них свои типы рецептов и своя еда,
   часть рецептов сборка удаляет скриптами — показывать только живые.

## Связи с другими разделами

- Ботаника: в «Куда идёт» вместо числа «сборные блюда: N» — ссылки на семейства («идёт в сэндвичи, супы»).
- Рецепты: фильтр по семейству.
- Справочник еды: у продукта — «в какие сборные блюда годится».
