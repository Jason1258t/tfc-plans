# План: раздел «Электричество» в справочнике

Статус: **начато** (2026-10-14). Вкладка `Справочник → Электричество` (`/reference?tab=power`), подразделы слева.
Данные — `scripts/mods/power.mjs` → `public/power.json` (значения по умолчанию и коэффициенты формул из байткода),
настройки сервера — Firestore `config/config__electroenergetics-server.toml` и `config__immersiveengineering-server.toml`.

## Что за энергия в сборке (проверено по jar)

- **Create** — вращение, SU = влияние × об/мин. Источники: колёса, ветряки, паровой двигатель, дизели CDG и т. д.
- **Create Electro Energetics** (`electroenergetics`, 1.1.2) — настоящая электросхема: напряжение, ток, сопротивление,
  трансформаторы, предохранители, провода с нагревом и изоляцией. Единственный мост между Create и IE.
- **Immersive Engineering** — FE/t, провода LV/MV/HV с пределом и потерями. Потребители: машины IE и Advanced TFC Tech.
- Других носителей FE/кинетики, связывающих системы, нет (проверено поиском `IEnergyStorage` и `KineticBlockEntity`
  по всем jar): FE ещё у мелочей (рюкзаки, CC, FTB Quests), кинетика — у аддонов Create без электричества.
- **Вращение TFC** — отдельная система (ветряки и колёса TFC, жернова); Create → TFC — преобразователь `c2tfc`.
  `woodencog:wooden_generator` и `ct_transformer` сборка удалила (скрипт `woodencog_fix.js`).

## Формулы EE (по байткоду)

- Генератор: ротор считает статоры по 4 сторонам поперёк оси (`AlternatorRotorBlockEntity.lazyTick`). Выработка
  щёточного узла = Σ статоры × |об/мин| × `rotorPowerMultiplier` (48) Вт; ЭДС = выработка / `rotorFullLoadCurrent` (100 А).
  Нагрузка на вал = статоры × 0,125 × 48 × `rotorStressMultiplier` = 6 SU на статор за 1 об/мин, **от потребления не
  зависит**. Генератор — источник с запасом энергии ≤ 10 × выработка.
- Двигатель: запас SU = V² / `motorResistance` (30 Ом); сопротивление 0,8 × min(6R, R / нагрузка), нагрузка ≥ 0,05.
  Не крутится при U ≤ `motorMinVoltage` (80 В). «Плавающий» режим: обороты = запас SU / число на шкале.
- Преобразователь: 1 FE/t = `wattFeTConversionRate` Вт (мод 34, **сервер 24**); буфер `converterMaxPower` × 1000;
  режим меняется ключом; источник держит 0–4320 В (шкала 0–432 × 10, по умолчанию 100 В); как потребитель —
  сопротивление max(20, U² / свободное место в буфере). FE — блок за задней гранью.
- Отсюда находка: генератор 8 Вт/SU, двигатель 1,25 Вт/SU на полной нагрузке → петля «вал → EE → вал» в плюс при
  достаточном напряжении. **В игре не проверялось**; на сайте помечено.
- Сервер изменил: `wattFeTConversionRate` 34 → 24, `resistiveHeaterResistance` 45 → 15. В IE: `dynamo_output` 3 → 2.

## Дальше

1. **Провода EE**: `CEEWireTypes` — у каждого вида сопротивление на метр, предел изоляции по напряжению,
   `maxTemperature` (3540, 5000, 6000, 10000, 15000 — разобрать единицы и модель нагрева), замена на «перегретый»,
   длина пролёта. Нужна модель нагрева, чтобы посчитать допустимый ток; калькулятор потерь линии I²R.
2. **Трансформаторы EE**: соотношение витков, мощность магнитопровода, радиаторы и масло (из ponder-текстов —
   «повышают мощность»), перегрузка. Вариак, регулятор напряжения.
3. **Последствия перегрузок**: перегорание лампы и предохранителя, `componentDamage`, электротравма.
4. **Генерация Create**: SU источников (`create-server.toml` → `stressValues.v2.capacity`, импортировать; значения по
   умолчанию — из кода Create), колёса pickywheels (ветер TFC), дизели CDG (SU и расход топлива — связать с
   «Жидким топливом»).
5. **Генерация IE**: сколько вращения дают водяное колесо и ветряк IE, термоэлектрический генератор (источники
   тепла, в т. ч. магма TFC из датапака сборки), дизельный генератор и расход топлива.
6. **Потребители**: нагрузка механизмов Create (SU), расход машин IE по рецептам (`energy` в рецептах уже есть в
   каталоге), Advanced TFC Tech, конденсаторы IE (`machines.capacitors.*` — разбор вложенных конфигов).
7. Калькулятор «линии целиком»: генератор → трансформатор → провод N м → потребители, с просадкой и потерями.
8. Нагреватель EE и уровни нагрева чаши Create (уже разбирали для стали, см. `docs/STATE.md`) — перенести сюда.
9. Вращение TFC и `c2tfc` — решить, входит ли в раздел.
