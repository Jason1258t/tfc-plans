# План: география TFC Real World

Статус: **этапы 1–4 сделаны** (2026-10-07). Осталось: сверить параметры мира с серверным конфигом мода и с игрой
по 3–5 городам — до этого на карте висит предупреждение. Подписи «регион» берутся по ближайшему городу; высота и
климат в точке не показываются (кодировка PNG мода не разобрана), только слоями карты.

## Зачем

Мир сборки построен по реальной Земле, поэтому игроки постоянно спрашивают друг друга: «где в блоках Лондон», «что за регион на x=12000, z=-3400», «где база и куда идёт экспедиция». Сейчас ответы ищут в игре или считают вручную. Страница «Карта» отвечает на эти вопросы прямо на сайте и привязывает к местам задачи.

## Что есть в сборке (проверено в `TFC-Real-World-NeoForge-1.21.1-4.1.4.jar`)

| Данные         | Где                                                                 | Что внутри                                                                                                                  |
| -------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Города         | `data/tfc_real_world/geography/default/waypoints/*.json` — 401 файл | `latitude`, `longitude`, `capital`, `parent` (подрегион), названия на 13 языках включая `ru_ru`, описание                   |
| Иерархия       | `…/continents` (10), `…/regions` (53), `…/subregions` (370)         | континент → регион → подрегион, названия на ru                                                                              |
| Профили карты  | `data/tfc_real_world/profiles/default/<профиль>/settings.json`      | центр спавна (lat/lon), `horizontal_scale`, `vertical_scale`, границы долгот и широт, проекция `EQUAL_EARTH`                |
| Карты-картинки | `…/<профиль>/maps/*.png`, 1280×640                                  | континенты, высоты, климат по Кёппену, температура, осадки, горячие точки                                                   |
| Формулы        | `util/projection/ProjectionManager`, `EqualEarthProjectionStrategy` | `classicToGeographic`, `geographicToClassic`; есть повторение мира за краями карты (`tileIndex`, `floorMod`, «unreflected») |

Профили: `full_equal_earth` («Весь мир», радиус 40 000 × 20 000 блоков), `old_world_equal_earth` («Старый Свет», 20 000 × 20 000), `new_world_equal_earth`.

**Масштаб.** В конфиге мода `horizontal_scale` описан как «Horizontal map radius in blocks». Для «Всего мира» ширина карты — 80 000 блоков на 360°, то есть около 500 м на блок по экватору. Пиксель встроенных PNG ≈ 62 блока. _На нашем сервере радиус 100 000: около 200 м на блок по экватору, ~180 м в Европе (Лондон — Париж ≈ 1900 блоков)._ Детальность — регионы и крупные города, не улицы.

**Чего не хватает.** Реальные параметры нашего мира задаются в **серверном конфиге мода** в папке мира. Это профиль (по умолчанию `default:full_equal_earth`), масштабы и центр спавна: `spawn_center_longitude` / `latitude`, `spawn_center_x` / `z`. Если на сервере их меняли, значения из профиля по умолчанию не подойдут. **Нужен этот файл с сервера.** _Получен 2026-10-09: профиль `DEFAULT:FULL_EQUAL_EARTH`, `horizontal_scale = 100000`, `vertical_scale = 50000`, спавн GEOGRAPHIC 45.47° / 10.94°. Импортируется в Firestore `config` скриптом `npm run config` (README, «Конфиги сервера»)._

## Что делаем

### Этап 1. Данные и формулы

1. `scripts/build-items.mjs` дополнительно собирает `public/geo.json`:
   - города: id, ru и en название, lat/lon, столица, подрегион;
   - иерархия: континенты, регионы, подрегионы с ru-названиями;
   - профили: settings без списков точек.

   PNG карт выбранного профиля копируются в `public/geo/`. Источник — jar из `mods/`, тем же механизмом, что предметы и рецепты.

2. `src/lib/geo.ts` — перенос `ProjectionManager` и `EqualEarthProjectionStrategy` на TS один в один, включая повторение мира за краями. Функции:
   - `toBlock(lat, lon) → {x, z}`;
   - `toGeo(x, z) → {lat, lon}`;
   - `nearestWaypoints(x, z, n)`;
   - `regionAt(x, z)` — ближайший подрегион по городам, точных границ в данных нет.
3. Параметры мира — документ Firestore `settings/world`: профиль, масштабы, центр спавна. Он правится на сайте в настройках карты, чтобы после смены настроек сервера не нужен был деплой.
4. Проверка: юнит-тесты на обратимость (`toGeo(toBlock(p)) ≈ p`) и **сверка с игрой** по 3–5 городам. В игре встать в город (у мода есть точки и достижения за посещение) и сравнить координаты из F3 с сайтом. Без этой сверки этап не считается готовым.

### Этап 2. Конвертер и поиск

Страница «Карта», верхняя панель:

- **Поиск города** по ru и en названию с подсказками: x/z, кнопки «копировать координаты» и «копировать `/tp`».
- **Ввод координат** любым способом: `x z`, `lat lon` или вставка строки из F3. В ответ — ближайшие города с расстоянием в блоках и километрах, подрегион и регион, широта и долгота, климатическая зона по Кёппену и высота по карте мода (оценка по пикселю).
- **Расстояние и направление** между двумя точками: «от базы до Каира — 6 240 блоков на юго-восток».

### Этап 3. Карта

Под панелью — карта из PNG мода, без внешних тайлов:

- **Слои**: континенты, высоты, Кёппен, температура, осадки. Переключаются, у климата есть полупрозрачный режим.
- **Навигация**: зум и перемещение мышью и пальцами, курсор показывает x/z, lat/lon и регион.
- **Метки**: столицы видны всегда, остальные города появляются при приближении; места задач (этап 4); клик по метке открывает карточку.
- **Реализация**: canvas, без Leaflet. Изображение одно и маленькое, свой код проще и легче библиотеки.

### Этап 4. Места у задач

- В задаче появляется необязательное поле «Где»: x/z (поле ввода или поиск города) и подпись. На странице задачи — ссылка «на карте».
- На карте метки задач раскрашены по группам и фильтруются по группе и статусу (выполненные по умолчанию скрыты).
- Тип: `Task.place?: { x: number; z: number; label?: string } | null`, плюс проверка в `firestore.rules`.

## Вопросы

1. ~~**Конфиг мода с сервера.**~~ Готово: `npm run config`. Нужен файл из папки мира с настройками TFC Real World. Его имя и путь я определю по коду мода, если понадобится; проще прислать содержимое `serverconfig/` целиком. Нужно знать профиль, масштабы и центр спавна.
2. **Места только у задач или отдельно?** Базы, шахты, порталы удобно хранить и без задачи — понадобится коллекция `places` со своей страницей. Предлагаю начать с поля у задач и расширить при необходимости.
3. **Какие слои нужны.** Предлагаю континенты, высоты и Кёппен. Температура, осадки и горячие точки — по желанию.
4. **Высота по карте** — это лишь оценка по PNG, а не реальный рельеф сгенерированного мира. Показывать ли её, или это скорее запутает?

## Не входит

- Реальные тайлы с зумом до улиц и наложение исследованного (вариант с серверным рендерером мы обсуждали отдельно).
- Точные границы регионов: в данных мода только точки, поэтому «регион» определяется по ближайшим городам.
