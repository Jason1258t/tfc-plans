# Ядерная энергетика: уран в дело

**Статус: отложено** (2026-10-21). До этого этапа в мире далеко; решение — после обсуждения с игроками.
Ничего не скачано и не разобрано: всё ниже о модах — по их страницам и списку изменений, **не по jar**.
**В игре ничего не проверялось.**

## Зачем

Уран в сборке есть (уранинит TFC+IE генерируется, моется в tfcorewashing, плавится), но применения почти нет.
Проверено по рецептам сборки (MCP `recipes_using #c:ingots/uranium`, 2026-10-21): только пластины, листы, провод,
стержень и шестерня IE и робот-волк IE (`immersiveengineering:blueprint/robot_wolf`). Нужен потребитель — реактор.

Два мода вместе ставить не стоит: две радиации, два урана, два реактора. Код Going Nuclear брать нельзя
(закрытая лицензия), так что «слить» их можно только своим аддоном, повторив механику.

## Что придётся связывать с TFC (общее для обоих)

1. **Руды.** Ожидаемо: генерация модов ищет ванильный камень, которого в мире TFC нет — их руд не будет (проверить).
   Сырьё — уранинит TFC+IE; нитрат — селитра TFC; торий — источника нет (побочный продукт уранинита или убрать).
2. **Бесконечный уран из булыжника** (Create Nuclear) — убрать KubeJS.
3. **Теги:** уран мода ↔ `c:ingots/uranium`, `c:dusts/uranium` IE; лишний слиток убрать из рецептов.
   Руду TFC (уранинит) — в теги радиоактивного, чтобы «светила».
4. **Свинец** для защиты — проверить, есть ли в сборке (галенит TFC+IE).
5. **Энергия** — SU → генератор Electro Energetics → провода; расчёт — в раздел «power» справочника.
6. **Аварии** — на старте отключить взрыв/расплавление в конфиге сервера (`config_propose`): как изменение биома
   уживётся с климатом TFC — неизвестно.

## Пути и оценка

| Путь | Цена | Что получим |
| --- | --- | --- |
| Create Nuclear + слои 1–2 | дни | реалистичная цепочка топлива, реактор простой (сразу SU) |
| + слой 3 | ещё недели | приборы и учёт дозы |
| + слой 4 | месяцы, с проверками игроков | уровень Going Nuclear |
| Going Nuclear + слои 1–2 | дни | всё сразу, но мод сырой и с закрытой лицензией |

Слои (если делать своим аддоном поверх Create Nuclear):

1. **Минералы и жилы** — легко: жилы TFC — данные (датапак). Новые руды (торий, урановая смолка) — блоки под
   каждую породу (20+), KubeJS или маленький аддон.
2. **Цепочка топлива** — средне, почти без кода: KubeJS на машинах Create (дробление, промывка, жёлтый кек,
   азотная кислота, «обогащение» сборкой по шагам) → топливо реактора Create Nuclear.
3. **Приборы** — средне, аддон: Гейгер, дозиметр, полоска дозы, свинцовый костюм; расширять радиацию Create Nuclear.
4. **Реактор уровня Going Nuclear** — капитально: мультиблок, физика, пар, турбина, пульт, центрифуги, модели,
   Ponder. Для сравнения: EE Extras — ~3 тыс. строк; здесь в 3–5 раз больше. Проверить можно только в игре.
5. **Осадки и изменение местности** — не делать.

Рекомендация на момент записи: Create Nuclear + слои 1–2, реактор менять позже, если приживётся.

## Вопросы игрокам

- Нужна ли ядерка вообще и на каком этапе (после IE? после электрификации EE?).
- Простой реактор (Create Nuclear) или «симулятор» (Going Nuclear), даже ценой сырости мода?
- Радиация: включать вред от предметов в инвентаре и защиту, или только антураж?
- Аварии: разрешать взрыв/осадки или отключить?

## Первый шаг, когда вернёмся

Скачать jar выбранного мода (с согласия) в отдельную папку, разобрать MCP (`jar_find`, `jar_read`, `jar_javap`):
версия Create в `neoforge.mods.toml`, рецепты и предметы цепочки, worldgen (biome modifiers), теги, конфиг.
Потом — точный список KubeJS и правок конфига.
