# Папка config/ сборки: что в ней есть и что из этого можно сделать

Разбор архива `config.zip` (597 файлов, 45 МБ) от 2026-10-13. Это заметки на будущее, не план с датами.
Архив лежит у пользователя; в репозиторий и в Firestore из него попало только перечисленное в разделе «Сделано».

## Как устроены слои настроек

`config/` — конфиг сборки, `serverconfig/` — переопределения сервера поверх него (так написано в `readme.txt` самого
NeoForge). Пример: радиус мира в `config/tfc_real_world/common.toml` — 40000×20000, а сервер ставит 100000×50000 в
`serverconfig/tfc_real_world/server.toml`. Сайт читает по слоям: сервер → сборка → значение мода по умолчанию из кода.

## Сделано

- `npm run serverconfig` принимает и `config/`: слой определяется по папке (`serverconfig/` → `server`, `config/` → `config`).
- В базу по умолчанию идут только конфиги модов по соглашению NeoForge (`*-server.toml`, `*-common.toml`,
  `<мод>/server.toml`, `<мод>/common.toml`). Клиентские, `.bak`, файлы с нестандартными именами и файлы с ключами,
  похожими на секрет (token, password, cookie…), не импортируются: коллекцию `config` читает любой посетитель сайта.
- Импортированы `tfc-server.toml`, `tfc-common.toml` (и попутно `c2tfc-common`, `cuisinetfc-common`, `farmerstfc-common` —
  совпали по подстроке `--only`). Остальные 109 конфигов модов **не импортированы** — ждут решения пользователя.
- Ботаника берёт из них множитель роста культур (1) и длину месяца (15 суток вместо 8 по умолчанию).

## Чего в архиве нет

- **Иконок предметов нет.** PNG здесь — оформление меню (`fancymenu`, 28 МБ) и фоны квестов. Иконки своих предметов
  сборки взяты из `kubejs/assets/` (сделано: `npm run kubejs` сохраняет assets и собирает `kubejs-items.json`).
- **Рецептов нет**: они в jar и в `kubejs/`.
- Общие карты JourneyMap (`jmsharedmaps`, 10 МБ) — это списки известных серверов с адресами, а не тайлы карты.

## Не трогать

- `CSC/config.toml` — есть ключи, похожие на секреты. `jmsharedmaps/known/` — адреса серверов.
  `net_music_login_need.toml` — поле cookie (сейчас пустое). В базу и в репозиторий это не кладём.
