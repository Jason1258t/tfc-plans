# Ботаника: что разобрано и что осталось

Правило: всё, что показывает сайт, достаётся скриптом из jar текущей сборки (`npm run items`), руками ничего не вписано.
То, что моды задают кодом, читает `scripts/classfile.mjs` — свой разбор `.class` на Node, JDK не нужен.
**В игре ничего из этого не проверялось.**

## Сделано (`scripts/botany.mjs` → `public/botany.json`)

| Что | Откуда | Как |
| --- | --- | --- |
| Диапазон температуры и влажности | `data/<ns>/tfc/climate_range/{crop,plant}/*.json` | JSON |
| Плод, семена, куст-предмет | библиотека предметов | подбор по id (`<ns>:food/<имя>`, `<ns>:seeds/<имя>`, `<ns>:plant/<имя>`) |
| Сытость и порча плода | справочник «Еда» | по id плода |
| Расход N / P / K у культуры | перечисление с полями `nitrogen`, `phosphorous`, `potassium` (TFC: `blocks.crop.Crop`) | аргументы конструктора констант; порядок сверяется с порядком полей |
| Число стадий роста | то же перечисление | целые аргументы конструктора |
| Тип культуры | фабрика блока в конструкторе: `XCropBlock.create` | цель лямбды; при двух фабриках выбор по булеву аргументу |
| Сезоны кустов и деревьев по месяцам | перечисления с аргументом `Lifecycle[]` (TFC `FruitBlocks$Tree/StationaryBush/SpreadingBush`, Firmalife `FLFruitBlocks$…`) и статические массивы `X_STAGES` (банан, клюква) | массив из `<clinit>` |
| Дни роста саженца, высота куста | поля `defaultTicksToGrow`, `maxHeight` | связь «параметр конструктора → поле» из байткода конструктора |
| Порядок месяцев | `util.calendar.Month` | имена констант |
| Скорость роста и расхода удобрений | `CropHelpers`: `GROWTH_FACTOR`, `NUTRIENT_CONSUMPTION`, `NUTRIENT_GROWTH_FACTOR` | `ConstantValue` полей |

Покрытие на текущей сборке: удобрения — 30 культур из 30; сезоны — 24 из 25 кустов и деревьев (нет у винограда Firmalife).
Сборка печатает предупреждение, если перечисление не нашлось или в коде есть растение без `climate_range`.

## Оговорки

- Знак удобрений: по коду роста положительное значение расходует элемент почвы, отрицательное возвращает
  (`CropHelpers.growthTickStep`). Проверено по байткоду, не в игре.
- Срок созревания: рост идёт от 0 до 1 со скоростью `GROWTH_FACTOR` за тик, удобрения добавляют до
  `NUTRIENT_GROWTH_FACTOR` сверху; в игре есть случайный множитель 0,9–1,1 — он не учтён.
- Число стадий — это вид растения, а не время: срок созревания у всех культур общий.
- Разбор держится на именах полей и устройстве перечислений мода. После обновления TFC смотри предупреждения сборки.
