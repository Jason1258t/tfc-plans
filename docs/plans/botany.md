# Ботаника: что есть и что разобрать потом

Статус: **простая версия сделана** (вкладка «Ботаника» в справочнике). Остальное ниже — по порядку полезности.
Сводка по источникам собрана по списку классов и байткоду `TerraFirmaCraft-NeoForge-1.21.1-4.2.9.jar`;
значения полей **не разобраны и в игре не проверялись**.

## Уже есть (`scripts/botany.mjs` → `public/botany.json`)

- Климатический диапазон: температура °C (`min/max_temperature`), влажность % (`min/max_hydration`).
  Источник — `data/<ns>/tfc/climate_range/{crop,plant}/*.json`, это 30 культур, 13 кустов, 11 деревьев, 1 прочее
  (TFC, Firmalife: какао, инжир, виноград, паслён, ананас; TFC IE Addon: конопля).
- Плод / семена — подбор по id предмета (`<ns>:food/<имя>`, `<ns>:seeds/<имя>`); у какао, винограда, паслёна, конопли
  предмета не нашлось — показано по имени файла.
- Еда: сытость и порча берутся из уже собранного справочника «Еда» по id плода.
- Фильтр «подходит при T °C и влажности H %», сортировка по холодостойкости/жаростойкости.

## Разобрать позже

| Что | Где лежит | Как достать | Зачем |
| --- | --- | --- | --- |
| Расход/возврат азота, фосфора, калия у культуры | enum `blocks.crop.Crop`: три float в конструкторе (WHEAT: 1.0 / −0.3 / −0.3) | `javap -c -p` статического инициализатора; знак значений уточнить по `CropHelpers` | севооборот и подбор удобрений — главный вопрос «что сажать после чего» |
| Число стадий роста культуры | тот же конструктор, последний `int` (WHEAT: 8) | то же | время созревания = стадии × время стадии |
| Время одной стадии роста | `CropBlockEntity` / `TickCounterBlockEntity` + конфиг TFC (множитель роста) | байткод + `serverconfig` с сервера (есть импорт конфигов) | дни до урожая; на сервере множитель может отличаться |
| Тип культуры: обычная / двойная / лазающая / стелющаяся / срываемая | фабрики блоков в `Crop` (`DoubleCropBlock`, `ClimbingCropBlock`, `SpreadingCropBlock`, `PickableCropBlock`) | по классам фабрик в байткоде | нужны ли опоры/жерди, как собирать |
| Урожай и семена с растения | `data/tfc/loot_table/blocks/crop/*.json`, `…/plant/*_bush.json` | разбор loot_table: количество, функции | сколько еды и семян с грядки |
| Сезонность кустов | enum `FruitBlocks$StationaryBush` / `$SpreadingBush`: массив `Lifecycle` по месяцам (DORMANT / HEALTHY / FLOWERING / FRUITING) | `javap` статики enum | в какие месяцы плодоносит; календарь на карточке |
| Сезонность деревьев, время роста саженца | enum `FruitBlocks$Tree`: `Lifecycle[]`, `defaultTicksToGrow`, цвет цветения | то же | то же + «сколько ждать плодов» |
| Банан, какао, виноград, ананас, инжир | у банана свой класс (`BananaPlantBlock`), у Firmalife — Java аддона | отдельный разбор jar аддона | у них свои правила роста, не из `FruitBlocks` |
| Дикие культуры: где встречаются | `data/tfc/worldgen/configured_feature/plant/wild_crop/*` (59) и `placed_feature` + теги биомов | разбор фич: биомы/климат/редкость | где искать дикую форму, откуда брать семена |
| Что нужно для роста: освещение, вода (рис), почва | классы `FloodedCropBlock`, проверки в `CropBlock`/`CropHelpers` | байткод | рис растёт в воде, остальные — на возделанной земле |
| Куда идёт урожай | `public/recipes.json` | поиск рецептов, где плод — вход | цепочка «плод → еда/сушка/масло» на карточке |
| Привязка к нашей карте | `public/geo.json` — карты температуры, осадков, Кёппен | пересчёт мировых температур/осадков в °C и влажность TFC | слой «где на нашем мире растёт X» |

## Оговорки

- Диапазоны — «вне них не растёт»: как именно TFC штрафует рост рядом с границей, не проверялось.
- Привязка влажности к осадкам в мире Real World — отдельный вопрос, у карты своя шкала.
- Все числа — из jar сборки; датапак или KubeJS сервера могут их переопределять (как и в остальном справочнике).
