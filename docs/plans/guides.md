# Гайды: документы в Firestore со встроенными калькуляторами

Статус: **сделано** (2026-10-15). Первый раздел — «Электричество» (`/reference?tab=power&sub=guides&g=<id>`).

## Зачем

Раньше шесть гайдов были React-компонентами в одном файле на 2261 строку: править мог только программист через деплой,
текст был перемешан с вёрсткой, у каждого из семи калькуляторов — свои поля и вывод. Теперь статья — Markdown-документ
в Firestore, правят все игроки прямо на сайте, калькулятор описывается в самой статье.

## Как устроено

- **Хранение.** `guides/{id}`: `section`, `title`, `summary` («Коротко» — в карточке и плашкой в статье), `body`,
  `icon` (предмет), `group` (заголовок в списке), `order`, `checked` (`game` / `server` / `code` / `none` — значок
  «насколько проверено»), `hidden` (снят с публикации), `updatedBy`, `createdAt`, `updatedAt`. Каждое сохранение пишет
  и версию в `guides/{id}/revisions` (одним batch). Стирать нельзя ни статьи, ни версии — только снимать с публикации.
  Правила — в `firestore.rules`.
- **Список** — карточки по группам: значок, заголовок, «Коротко» с живыми числами, значок проверки, дата. Снятые — в
  свёрнутом блоке внизу.
- **Правка** — кнопка «Править»: поля, текст слева, живой предпросмотр справа (калькуляторы работают), справка со всеми
  именами формул. Если статью сохранил кто-то другой, пока вы правили, — спросит. «История» — все версии, любую можно
  вернуть (возврат тоже становится версией).
- **Загрузка** — подписка на `where(section == …)` при открытии вкладки; код гайдов (разборщик, YAML, редактор) —
  отдельный ленивый чанк.
- **Файлы** — `npm run guides -- pull <папка>` / `push <файл|папка>` (REST от `firebase login`, подпись — `TFC_NICK`).
  Источник правды — Firestore; в git статьи не хранятся.

## Формат статьи

Обычный Markdown (GFM: таблицы, списки, `> заметка` — плашка) плюс:

- `{{выражение | формат}}` — живое значение. Формат: число знаков, `watts`, `pct`, единица: `{{x | 1 В}}`. Если
  выражение — просто настройка (`{{ee.Voltages.wireMaxVoltage | В}}`), у числа подсказка, откуда оно, и пометка
  «сервер», если сервер поменял значение мода.
- `[[мод:предмет]]` — предмет со значком, `[[мод:предмет|icon]]` — только значок.
- `[текст](guide:id)` — ссылка на гайд, `[текст](/reference?tab=addons)` — на раздел сайта.
- строка `::имя параметры` — виджет раздела (рисунок, который разметкой не описать): `bridge-diagram legs=3 cap`,
  `generator-diagram`, `line-diagram`, `load-chart`.
- блок ` ```define ` — «имя: формула» по строкам, свои имена для всей статьи.
- блок ` ```calc ` — калькулятор (YAML):

```yaml
title: Калькулятор линии
inputs: # число; options / list — выбор; toggle — галочка; picker — кнопка подбора (ie-loads)
  kw: { label: Мощность, default: 20, min: 0.1, unit: кВт, picker: ie-loads }
  wire: { label: Провод, list: wires, default: heavily_insulated }
let: # промежуточные, по порядку; можно лямбды: ok: "k => …"
  i: kw * 1000 / 300
outputs: # плашки: value + fmt или text; hint, bad, warn, when
  - { label: Ток, value: i, fmt: 1 А, bad: i > wire.maxI }
notes: # строки под плашками: text, when, bad
chart: # столбики: values (список), max, left, right, caption
table: # rows (формула или список), columns: title, value + fmt или text, num, bad
footer: мелкий текст
```

Без `inputs` и `outputs` блок — просто таблица в тексте (так сделаны таблица проводов и «кому мешает переменный ток»).

**Формулы** (`src/lib/calcExpr.ts`) — свой разборщик, без `eval`: числа, строки, списки, `+ - * / % ^`, сравнения,
`and or not`, `a ? b : c`, `if(условие, то, иначе)`, поля, вызовы, лямбды `x => …`. Видны только имена из области:
общие функции (`src/lib/guideScope.ts`: `min max round range map find sum fmt watts plural…`) и имена раздела
(`src/lib/powerGuideScope.ts`: настройки `ee/ie/att/create`, `data` — power.json, `alternator`, `alternatorLoad`,
`matchRatio`, `rectifiedLoaded`, `pumpSpeed`, `wires`, `ratios`, `trMax`… — те же формулы, что в `power.ts`).
Прототипы закрыты: из статьи нельзя добраться ни до чего, кроме этих имён.

**Ошибки** не ломают статью: неизвестное имя, опечатка, «лишнее поле» (обычно формула с запятой в короткой записи
`{ … }` — её нужно взять в кавычки) показываются красным на месте; каждый калькулятор и виджет — в своём
ErrorBoundary.

## Новый раздел

Сделать `<раздел>GuideScope.ts` (имена и описания для справки), при необходимости виджеты и pickers, и обёртку как
`PowerGuidesSection.tsx` (`GuidesSection section="…" kit={…}`). Коллекция и правила общие.

## Проверено (2026-10-15)

- Все шесть статей открываются без ошибок; числа калькуляторов «генератор», «линия», «оптимальный режим» сверены
  со старыми формулами на тех же входах; подбор нагрузки из машин IE подставляет мощность; ширина телефона — без
  горизонтальной прокрутки.
- Сохранение с сайта проходит правила, пустой заголовок — отказ; версии пишутся и читаются (тестовая статья удалена).
- `pull` → тела статей совпадают с залитыми.
- Отличие от старой версии: калькулятор помпы считает падение на диодах с уточнением тока (как калькулятор
  выпрямителя), числа могут отличаться на доли вольта.
