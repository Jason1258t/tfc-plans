# mods/

Сюда кладутся jar-файлы модов сборки, например всё содержимое папки `mods` из лаунчера.
Их предметы появятся в подсказках сайта: названия (с русскими, если мод их содержит) и иконки.

```bash
npm run deploy    # заметит изменения в mods/, пересоберёт библиотеку предметов и выложит сайт
npm run items     # только пересобрать библиотеку (для локальной проверки через npm run dev)
```

- В git jar-файлы не попадают (см. `.gitignore`). На сайт попадают только названия и иконки.
- Моды без предметов (библиотеки, оптимизация) пропускаются сами.
- Если в папке есть jar TerraFirmaCraft, берётся он, а не версия с GitHub.
