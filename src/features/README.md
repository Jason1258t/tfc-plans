# features — действия и потоки

Сюда попадает код, который нужен **нескольким страницам** и делает что-то от имени человека: редактор гайда,
сравнение задач, загрузка датапака, конструктор KubeJS. Импортировать можно `features/*`, `entities/*`, `shared/*`.
Одной странице достаточно `pages/<x>/`; правила — в AGENTS.md («Where code goes»).
