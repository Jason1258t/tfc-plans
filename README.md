# TFC Планы

Таск-менеджер в стиле Minecraft для совместной игры в сборку на **TerraFirmaCraft 1.21.1**.
React + Vite + Firebase (Firestore, Anonymous Auth, AI Logic / Gemini).

## Что умеет

- **Список задач** с вкладками «Активные» / «Выполненные». Задача закрывается кружком слева, цвет кружка — важность.
- **Важность**: низкая, обычная, высокая, критическая.
- **«Что важнее?»** — попарное сравнение задач. Каждый выбор меняет Elo-рейтинг, и сортировка
  «По рейтингу» со временем отражает общее мнение. Помогает, когда важность трудно сравнить напрямую.
- **Создание и редактирование в одном окне**: название, важность, статус, группа, исполнитель, описание и ресурсы
  заполняются сразу. Кнопка «Создать с планом» сразу открывает документ.
- **Описание в Markdown** со ссылками на предметы: `[[tfc:metal/ingot/bronze|4]]` превращается в иконку,
  русское название и количество.
- **Чеклист ресурсов**: предмет и «собрано X из N» плюс обычные пункты. В строке задачи видно, что ещё собрать.
- **Документы (артефакты)** открываются панелью справа от списка, как артефакты в ИИ-чатах, или на всю
  страницу. Markdown-редактор, предпросмотр, автосохранение, вставка предметов.
- **Агент Gemini** внизу документа, в формате чата: быстрые запросы, свой вопрос, работа с выделенным
  фрагментом. Ответ можно добавить в конец, вставить в курсор, заменить им фрагмент или весь документ,
  а ресурсы из него — перенести в чеклист задачи.
- **Группы** задач с иконкой предмета, фильтры: поиск, важность, «мои».
- **Подпись ником** без регистрации: ник хранится в куке `tfc_nick`. Кнопка «Взять себе» назначает исполнителя.
- **Библиотека предметов**: 6600+ предметов TFC и ванили с русскими названиями и иконками.
- Светлая и тёмная тема (по системной настройке), палитра взята из Minecraft.

## Быстрый старт

```bash
npm install
npm run dev
```

При первом `dev`/`build` автоматически собирается библиотека предметов (`npm run items`, около минуты):
скачивается `client.jar` 1.21.1 с серверов Mojang и делается sparse-клон репозитория TFC.
Нужны `git` и интернет.

Без настроенного Firebase приложение работает в **локальном режиме**: данные лежат в `localStorage`
браузера, в шапке горит метка `offline`, Gemini выключен. Так удобно разрабатывать интерфейс.

## Firebase

Проект уже создан: **`tfc-plans-fd2c`** (`.firebaserc`). Включены Firestore (eur3), анонимный вход
(`firebase.json` → `auth`) и AI Logic с Gemini Developer API. Конфиг веб-приложения лежит в `.env.local`
(он не в git, но эти значения не секретные: веб-конфиг Firebase и так виден в браузере).

```bash
npm run deploy          # сборка + hosting + правила + auth
npm run deploy:rules    # только правила Firestore
```

Сайт: https://tfc-plans-fd2c.web.app

Как настроить новый проект с нуля через CLI:

```bash
firebase projects:create <id>
firebase apps:create web "TFC Plans Web" --project <id>
firebase apps:sdkconfig WEB <appId>          # → .env.local по образцу .env.example
firebase deploy --only firestore:rules       # заодно включает Firestore API
firebase firestore:databases:create "(default)" --location eur3
firebase deploy --only auth                  # анонимный вход
FIREBASE_CLI_EXPERIMENTS=ailogic firebase ailogic:providers:enable gemini-developer-api
```

После этого один раз откройте в консоли **AI Logic → Get started → Gemini Developer API**: только этот
шаг выдаёт Gemini-ключ. Без него агент отвечает ошибкой «genai config not found».

Модель Gemini задаётся в `VITE_GEMINI_MODEL` (по умолчанию `gemini-3.8-flash`).

> Про безопасность. Настоящей авторизации нет, так что любой, у кого есть ссылка, может читать и
> править задачи. Это сознательный выбор для игры с друзьями. Чтобы чужие не тратили квоту Gemini,
> включите [App Check](https://firebase.google.com/docs/app-check) для AI Logic и Firestore.

## Библиотека предметов

`scripts/build-items.mjs` создаёт:

- `public/items.json` — `[{ i: id, e: имя en, r: имя ru, t: путь иконки }]`;
- `public/icons/**.png` — текстуры, которые используются как иконки.

Иконка берётся из модели предмета: цепочка `parent` → `layer0` / `all` / `side` / …
Для блоков это одна сторона, а не 3D-рендер. Текстуры, которые TFC генерирует в игре (дерево разных
пород, жидкости в вёдрах), заменяются базовыми.

Сгенерированные файлы **не коммитятся**: это ассеты Mojang и авторов модов. Пересобрать заново:
`npm run items -- --fresh`.

### Добавить аддон сборки

Допишите репозиторий мода в `MOD_SOURCES` в `scripts/build-items.mjs`:

```js
{ name: 'firmalife', repo: 'https://github.com/eerussianguy/firmalife.git', branch: '1.21.x',
  assetsDir: 'src/main/resources/assets', namespaces: ['firmalife'] },
```

Скрипт берёт `lang/en_us.json` и `ru_ru.json`, а предметом считает каждый ключ `item.*` или `block.*`,
у которого есть модель предмета.

## Модель данных (Firestore)

| Коллекция   | Поля                                                                                                                                     |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `tasks`     | `title`, `description` (md), `status`, `priority` 0–3, `rating` (Elo), `checklist[]`, `icon`, `groupId`, `author`, `assignee`, `createdAt`, `updatedAt` |
| `groups`    | `name`, `icon`, `order`, `author`, `createdAt`                                                                                           |
| `artifacts` | `title`, `content` (md), `taskId`, `author`, `updatedBy`, `createdAt`, `updatedAt`                                                       |

Пункт чеклиста: `{ id, text, itemId?, qty?, got?, done? }`. Если есть `itemId`, это ресурс «собрано got из qty»,
иначе обычная галочка.

## Структура

```
scripts/build-items.mjs      сборка библиотеки предметов
src/data/store.ts            CRUD + подписки: Firestore или localStorage
src/data/DataContext.tsx     живые данные для всего приложения
src/lib/items.ts             загрузка и поиск предметов
src/lib/gemini.ts            запросы к Gemini (стриминг, извлечение ресурсов)
src/lib/tasks.ts             прогресс, сортировки, Elo
src/components/              UI-кирпичики (ItemPicker, Checklist, Markdown, …)
src/pages/                   список задач, документы, документ на всю страницу
firestore.rules              правила доступа
```
