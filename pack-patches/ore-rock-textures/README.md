# Руды на породах TFC

Накладка для [dev-задачи #363](https://tfc-plans-fd2c.web.app/dev?task=363). Содержит платиновую руду из #362, поэтому
её можно установить поверх снимка, в котором предыдущего обновления ещё нет.

| Руда                    | Породы                                     |
| ----------------------- | ------------------------------------------ |
| Платиновая (сперрилит)  | Габбро                                     |
| Флюоритовая Destroy     | Гранит, риолит, известняк, доломит, мрамор |
| Титановая Rocketnautics | Габбро, базальт, диорит, гранит            |

Текстуры собраны из сырой породы TFC и цветных вкраплений соответствующих руд. Иконка сперрилита нарисована отдельно.
Платина сохраняет прежний блок `kubejs:ore/platinum`: габбро — её единственная порода, и текстура обновится также у
уже сгенерированных блоков. Флюорит и титан получают новые варианты блоков для каждой породы. Они появляются в
новых чанках. При добыче выпадают обычные флюорит и сырой титан, с «Шёлковым касанием» — исходные блоки модов,
которые принимают действующие рецепты.

Редкость, глубина, объём жил и поверхностные индикаторы сохранены. Файл жилы флюорита из накладки имеет приоритет
над одноимённым файлом из ZIP «Destroy — руды в жилах TFC». Этот ZIP нужен для подключения жилы к генерации TFC
и отключения ванильной генерации руд Destroy.

## Проверка и установка

На test1a, прогон `20261115-122238-bcc6`, жилы разместили нужный блок во всех десяти сочетаниях «руда → порода».
Для прогона редкость выставлена в 1 в отдельной копии. Все блоки входят в тег разведки. Добыча каждого варианта
проверена через `loot … mine` с обычной алмазной киркой и с «Шёлковым касанием». PNG проверены по листу предпросмотра,
вид блоков в клиенте ещё предстоит проверить хосту.

Обновление `u20261115-132405-1cd8` включает содержимое #362 и заменяет ожидающее `u20261114-224107-c9bf`. Хост может
подписаться на новое обновление в тестовом профиле и перезапустить игру и сервер.

```bash
tfc admin updates subscribe u20261115-132405-1cd8 --profile тест
```
