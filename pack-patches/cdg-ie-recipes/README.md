# Исправление совместимости CDG с Immersive Engineering

Dev-задача [#118](https://tfc-plans-fd2c.web.app/dev?task=118). Накладка добавляет четыре файла в `kubejs/data`,
заменяя штатные рецепты Create Diesel Generators 1.3.8 по прежним идентификаторам. Требуются CDG и IE из сборки.

## Исправления

- Серебряная пластина: поле результата `item` заменено на `id`.
- Урановая пластина: убран пробел в имени поля `id `.
- Дюропластовая пластина: вместо несуществующей жидкости `c:phenolic_resin` указан жидкостный тег
  `c:phenolic_resin` через `neoforge:tag`; расход 250 мБ, форма `createdieselgenerators:bar`.
- Гербицид: исправлен формат жидкостного ингредиента — тег `c:ethanol` через `neoforge:tag`, 500 мБ.
  Поле времени `processingTime` заменено на читаемое установленной версией Create `processing_time`: 400 тиков.
  Серная и медная пыль, выход 500 мБ сохранены.

Материалы, количества, типы рецептов и условие присутствия IE сохранены. Другие способы получения остаются.
Путь `kubejs/data` выбран для точечного перекрытия до разбора рецептов: отдельная установка датапака в мир не нужна.

## Проверки

Через MCP прочитаны исходные рецепты, код `ProcessingRecipeParams`, `CastingRecipe`, `BulkFermentingRecipe`,
`CreateCodecs` и `TagFluidIngredient`, а также тег фенольной смолы из IE. Проверены каталог с KubeJS и датапаками
сайта и отсутствие существующих перекрытий этих четырёх id. Каталог сам по себе не проверяет кодеки игры:
ошибочные исходники в нём тоже отмечены как работающие.

Проверка конфликтов MCP для всех четырёх JSON: только намеренная замена собственного id, посторонних
пересечений не найдено. `npm run lint` — без ошибок; форматирование проверено Prettier.

На отдельном сервере NeoForge 21.1.251 с Create 6.0.10, CDG 1.3.8, IE 12.4.2, TFC 4.2.9 и KubeJS
накладка загружена через настоящий `kubejs/data`. Проверочная команда получила все четыре рецепта из
`RecipeManager` и проверила: выход каждой пластины — правильный предмет в количестве 1, теги ингредиентов
непустые, форма дюропласта распознана, расход смолы 250 мБ, расход этанола и выход гербицида по 500 мБ,
время гербицида 400 тиков. Все четыре проверки прошли; ошибок разбора этих четырёх рецептов нет.
Проверочный мод и журналы — временные файлы, в накладку не входят.

**Ограничение полной проверки:** отдельно запускался полный KubeJS снимка сборки (6 стартовых и 83 серверных
скрипта загружены без ошибок и предупреждений), но сервер останавливался до завершения загрузки ресурсов из-за
обращений модов к клиентским классам на dedicated-сервере. В Gradle дополнительно мешали сканирование папок
исходников TFC Registry API и dev-проверка DataManager в KubeJS TFC. Эти ограничения записаны в dev-задачу
[#133](https://tfc-plans-fd2c.web.app/dev?task=133); игровые jar не правились. Успешная проверка четырёх рецептов
выполнена на сокращённом стенде без полного набора скриптов. Совместимость с правилами полного KubeJS дополнительно
проверена по каталогу MCP и поиску исходников: существующих перекрытий или удалений этих четырёх id не найдено.
Успешный запуск всей сборки с накладкой не подтверждён.

В игре не проверялось: реальные механизмы, расход ингредиентов и отображение JEI/EMI.

## Установка и откат

```bash
npm run tfc -- admin propose pack-patches/cdg-ie-recipes --note "Исправлены четыре рецепта совместимости CDG с IE: серебро, уран, дюропласт и гербицид" --yes
```

Выложено обновление **`u20261028-203009-ce84`**, ожидает проверки и одобрения хостом.

Хост: `tfc admin updates pull u20261028-203009-ce84`, перезапуск сервера, проверка четырёх рецептов в JEI/EMI и механизмов,
затем `tfc admin updates approve u20261028-203009-ce84`. Проверить журнал: ошибок разбора этих четырёх id быть не должно.

Для отката убрать четыре файла из `kubejs/data/createdieselgenerators/recipe/compat/immersiveengineering/`
(`silver_sheet.json`, `uranium_sheet.json`, `duroplast_sheet.json`, `herbicide.json`) и перезапустить сервер.
Исходные ошибки CDG при этом вернутся. Публикация библиотеки рецептов — штатным процессом сервера сборки после
одобрения хостом; деплой сайта не требуется.
