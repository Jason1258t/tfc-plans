# Песчаник TFC из песка

Dev-задача [#349](https://tfc-plans-fd2c.web.app/dev?task=349). Накладка добавляет один серверный скрипт KubeJS,
существующие файлы не перезаписывает.

## Что меняется для игроков

- **Уплотнение Create: 4 песка TFC одного цвета + 250 мБ известковой воды → 1 сырой песчаник того же цвета.**
  Все 7 цветов: коричневый, белый, чёрный, красный, жёлтый, зелёный, розовый. Нужен механический пресс над чашей.
- Раньше цветной песчаник TFC можно было только добыть. Из сырого песчаника, как и прежде, делаются гладкий
  (зубило, камнерез), плиты, ступеньки и ограды; пиленый — штатными способами TFC.
- Ванильный песчаник не затронут: он по-прежнему собирается из 4 ванильного песка на верстаке.

## Почему с известью

Дробилка IE (аддон TFC-IE) превращает песчаник в 2 песка и с шансом 50 % даёт селитру. Без связки «4 песка → песчаник»
превращало бы почти бесконечный песок в селитру бесплатно. С известковой водой цикл стоит в среднем 4 песка и 500 мБ
известковой воды на одну селитру. Реалистично: природный песчаник — песок, сцементированный известью или кремнезёмом.

## Проверки

- Через MCP: у `tfc:raw_sandstone/<цвет>` не было ни одного рецепта получения; KubeJS сборки песчаник TFC и
  уплотнение не трогает. `recipe_conflicts` по всем 7 рецептам — конфликтов нет.
- Формат рецепта взят со штатного `create:compacting/andesite_from_flint` (жидкость — `neoforge:single`), известковая
  вода `tfc:limewater` — как в смешивании строительного раствора сборки.
- Стенд test1a (задание `20261113-140415-a75d`): сервер с полной сборкой и накладкой запустился, KubeJS — 87/87
  серверных скриптов без ошибок, ошибок разбора рецептов `tfc_plans:sandstone/*` нет. JEI/EMI и работу пресса без
  клиента не проверить.

## Установка хостом

Выложено обновление **`u20261113-140903-42aa`** к снимку `20261110-112536-9afd`, ждёт проверки хостом. Отправлено так:

```bash
npm run tfc -- admin propose pack-patches/sandstone-press --note "Песчаник TFC из песка: уплотнение Create с известковой водой" --yes
```

Хост забирает обновление (`tfc admin updates pull <id>`), перезапускает сервер и проверяет в JEI/EMI рецепт уплотнения
для любого цвета, затем `tfc admin updates approve <id>`. При отказе — убрать
`kubejs/server_scripts/tfc_plans/sandstone_press.js` и перезапустить сервер.
