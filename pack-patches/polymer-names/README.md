# Понятные названия пластиков и резины Destroy

Dev-задача #218. Русские названия четырёх материалов согласованы с гайдом «Нефть, пластики и синтетическая резина»:

| Предмет Destroy                    | Название                   |
| ---------------------------------- | -------------------------- |
| `polyethene` (PE)                  | Полиэтилен                 |
| `polypropene` (PP)                 | Полипропилен               |
| `polyvinyl_chloride` (PVC, ПВХ)    | Поливинилхлорид            |
| `polystyrene_butadiene` (SBR, СКС) | Бутадиен-стирольная резина |

SBR — бутадиен-стирольный каучук; в сборке он используется как синтетическая резина. Перевод исправляет опечатку
«Полиропилен» и раскрывает «ПВХ» и «СКС». Идентификаторы предметов, рецепты и теги не меняются.

Ключи и исходные переводы проверены через MCP в `assets/destroy/lang/en_us.json` и `ru_ru.json` кандидата
`destroy-1.21.1-0.4.6-eligibbs.jar`. Файл KubeJS дополняет переводы мода четырьмя ключами.

Обновление предназначено для профиля с Destroy; химия пока находится на приёмке. После установки обновления
клиент должен перечитать ресурсы (F3+T) или перезапуститься. Сам перевод не устанавливает Destroy.

## Установка и проверка

Обновление `u20261104-203745-9a77` загружено на pack server. Хосту: подписать профиль с Destroy
командой `tfc admin updates subscribe u20261104-203745-9a77 --profile тест`, перезапустить клиент и проверить
четыре названия в поиске предметов. После проверки — `tfc admin updates approve u20261104-203745-9a77`.

Проверены JSON, четыре ключа в jar, отсутствие конфликтующего файла в live snapshot и ожидающем обновлении
Destroy, предпросмотр загрузки и опубликованный гайд в браузере. Линтер без ошибок. Прогон полной сборки
через MCP не завершился до тайм-аута вызывающего процесса (180 секунд); свой сервер остановлен.
Успешный запуск сборки и отображение перевода в клиенте этим прогоном не подтверждены.
