# Единая известковая основа бетона

Dev-задача [#124](https://tfc-plans-fd2c.web.app/dev?task=124). Накладка к снимку сборки
`20261026-145741-8345`: добавляет один серверный скрипт KubeJS, существующие файлы не перезаписывает.

## Что меняется для игроков

- **3 песка + 3 гравия + 2 извести TFC → 8 порций сухой смеси TFC.** Подходят пески и гравий из общих тегов
  сборки, в том числе шлаковый гравий IE.
- Цветной порошок: та же партия и один краситель → 8 порошка. Можно сначала сделать обычную смесь, затем
  покрасить 8 порций одним красителем. Окраска в бочках TFC и отбеливание сохранены без изменения количества.
- Переход из датапака сайта «Бетон» сохранён: промывка одной сухой смеси TFC → один блок бетона IE. Датапак
  должен оставаться установленным; скрипт не дублирует его рецепт.
- Ручной бетон IE: 8 сухой смеси вокруг ёмкости с 1000 мБ воды → 8 блоков бетона IE.
- Смеситель IE: 1 сухая смесь + 1000 мБ воды → 1000 мБ жидкого бетона, 6400 RF. Код IE замещает воду
  бетоном строго 1:1, поэтому расход воды отличается от ручного рецепта.
- Дорожная смесь RnR: 1 сухая смесь TFC → 1 сухая смесь RnR. Дальше штатная бочка: 200 мБ воды на порцию →
  200 мБ дорожной смеси. Для заливки требуется 1000 мБ, то есть 5 порций. Распространение по подготовленному
  основанию и обработка дороги сохранены. Это дорожное покрытие на основании, а не обмен с бетонными блоками IE.
- Цветной жидкий бетон Diesel Generators: 1 соответствующий порошок + 100 мБ воды → 1000 мБ бетона.
  Прежний возврат порошка с вероятностью 25% убран, чтобы не давать скидку на связующее.

В итоге каждая новая сухая смесь содержит известь, а цветная — ещё и краситель. Это игровая известковая
рецептура; отдельное производство портландцемента не вводится. Готовые блоки, лестницы, плиты, армирование,
трубы в бетонной оболочке и накопленные игроками запасы не меняются.

## Как устроено

Скрипт точечно удаляет **36 исходных рецептов** и добавляет **52 рецепта** с пространством имён
`tfc_plans:concrete/…`: одну основу, 32 рецепта цветных порошков (два способа на цвет), 16 цветных жидких бетонов,
два рецепта IE и один переход RnR. Рецепты бочек, промывки и обработки готового бетона не удаляются.

Ингредиенты песка и гравия используют `c:sands` и `c:gravels`; известь — `tfc:powder/lime`, предметные красители —
`minecraft:<цвет>_dye`, как в исходных цветных рецептах сборки. Сетки содержат не больше девяти ингредиентов.

## Проверки

- Через MCP проверены все 16 цветных порошков и жидкостей, базовая смесь, бетон IE, дорожная смесь и
  получение красителей; других самостоятельных источников для этих смесей в текущем каталоге не найдено.
- Из jar прочитаны рецепты и код IE `ConcreteFluid`, `MixerRecipe`, `MixingProcess`, RnR
  `PouringConcretePathBlock`, `FluidBlockModRecipe`, CDG `ConcreteFluid`. IE при растекании способен затвердевать
  в несколько блоков/плит, а RnR распространяется по дорожному основанию: равенство конечной площади одному
  бетонному блоку не заявляется. Это сохранённая механика модов.
- Скрипт выполнен в отдельном Node-контексте с регистрацией рецептов: проверены уникальность id, точечные
  удаления и размеры сеток. Через `recipe_conflicts` проверены все 52 рецепта; 16 ожидаемых совпадений CDG
  относятся только к исходным рецептам, которые скрипт удаляет. Посторонних конфликтов нет.
- Проверено сохранение расхода сухой смеси в цепочках окраски, отбеливания и получения жидкостей: возвращаемый
  порошок CDG исключён. Твёрдый бетон обратно в сухую смесь не превращается.
- Выполнены lint и форматирование. **В игре не проверялось**: загрузка KubeJS/Rhino, отображение рецептов в JEI/EMI,
  ёмкости воды в ручном рецепте, реальная работа механизмов и затвердевание.

## Установка хостом

Выложено обновление **`u20261028-155634-36f7`**, ожидает проверки и одобрения хостом. Накладка отправлена штатно:

```bash
npm run tfc -- admin propose pack-patches/concrete-lime --note "Единая основа бетонных смесей: песок, гравий и известь; цветные варианты с красителем" --yes
```

Хост забирает предложенное обновление через `tfc admin updates pull <id>`, перезапускает сервер и проверяет:

1. Старый рецепт из 4 песков и 4 гравия исчез; новая партия требует 2 извести.
2. Все 16 цветов доступны прямо из сырья и через 8 готовых порций; бочки окрашивают/отбеливают 1:1.
3. Датапак «Бетон» установлен и промывка продолжает давать бетон IE.
4. Ручной IE расходует воду из ёмкости; смеситель выдаёт одно ведро на порцию смеси, не зависает без воды.
5. RnR принимает общую основу, бочка и заливка по дорожному основанию работают.
6. Diesel Generators не возвращает порошок; все цвета затвердевают и подходят для штатных применений.
7. Перезагрузка не создаёт дубликатов рецептов и не оставляет ошибок в журнале KubeJS.

После проверки хост одобряет обновление: `tfc admin updates approve <id>`. Данные каталога публикует сервер
сборки; локальный деплой сайта для этой накладки не требуется. При отказе от изменения убрать добавленный файл
`kubejs/server_scripts/tfc_plans/concrete_lime.js` и перезапустить сервер.
