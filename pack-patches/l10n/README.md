# Перевод китайских сообщений сборки

Сборка TerraFirma Rebirth писала часть сообщений прямо в скриптах KubeJS по-китайски. Здесь они заменены на ключи
перевода: игрок с русским клиентом видит русский текст, с английским — английский.

Что переведено:

- **Уборка выброшенных предметов** раз в 2 часа (`[群峦星360安全卫士]` → «[Уборщик] Через 60 с выброшенные предметы
  будут убраны…», «Убрано выброшенных предметов: N»).
- **Названия месторождений для бура Create** (Create Ore Excavation, 27 штук: «Месторождение угля»,
  «Месторождение гематита»…). Видны в поисковике жил, атласе и у бура. Id месторождений не менялись — уже найденные
  жилы просто получат новые названия.
- Заправка двигателя ведром, кафедра TFC и контроллер частот, обсидиан в аду, приветствие при первом входе,
  подсказки (ящик IE, мешок семян, козья шерсть).
- Сообщения в лог сервера — на английском.

Ники в списке благодарностей оставлены как есть.

## Как поставить (хост)

Выложено на сервер сборки как обновление `u20261022-150945-83a0`:

1. `tfc admin updates pull` — файлы лягут в папку игры и папку сервера (старые — в копию, вернуть: `tfc undo`).
2. Перезапустить сервер, проверить в игре.
3. `tfc admin updates approve u20261022-150945-83a0` — станет новой сборкой, игроки получат по `tfc pull`.

Файлы сделаны из версии сборки `20261022-095351-d765`. Если сборку обновили, лучше не копировать готовые файлы,
а наложить патч заново:

```bash
python3 apply.py "<папка игры>"
```

Скрипт меняет только найденные строки; если в новой версии скрипт сборки поменялся, он остановится и скажет где.

## Что осталось китайским (в модах, не в сборке)

Зашито в код модов, перевести можно только своим аддоном:

- `kaleidoscopetfctavern` — локатор винограда пишет «找到最近的…» и координаты.
- `firmalifehardcore` — отчёты команд отладки погреба (только для админа).
- Комментарии в конфигах (`c2tfc`, `farmerstfc`, `ktfcc`, `tfcsbu`, `sable_fix_mod` и др.) — видит только хост.
