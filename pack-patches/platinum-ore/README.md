# Платиновая руда (сперрилит)

Dev-задача [#362](https://tfc-plans-fd2c.web.app/dev?task=362). До неё в сборке не было ни одного источника платины,
палладия и родия: слиток и пыль превращались только друг в друга, плавку дроблёной платины Destroy и пепла свеклы
убрал KubeJS, а никелевые руды IE и Destroy в мире TFC не встречаются. Без них не собрать, например, каталитический
нейтрализатор Destroy.

## Что меняется для игроков

- **Платиновая руда** (`kubejs:ore/platinum`) — очень редкие мелкие жилы глубоко в **габбро** (y −80…−10, редкость 160,
  размер 8; для сравнения гарниерит — 20 и 30, титан — 80 и 18). Поверхностных признаков нет — искать киркой
  разведчика (руда в `#tfc:prospectable`). Нужна железная кирка или лучше; руда может обрушиться, как руды TFC.
- Руда даёт **кусок сперрилита** (`kubejs:ore/sperrylite`), с «Шёлковым касанием» — сам блок.
- Переработка куска:
  - дробилка IE: 3 пыли платины + 25 % ещё одна, 50 % пыль палладия, 20 % пыль родия;
  - дробильные колёса Create: 3 пыли платины, 30 % пыль палладия, 10 % пыль родия.
- Дальше — уже имеющаяся цепочка пылей: плавка в TFC (7 мБ на пыль), дуговая печь (14 пылей → слиток), брикеты.
  3 пыли = 21 мБ, как у обычной руды TFC.
- Текстуры **временные**: блок — никелевая руда Destroy, перекрашенная в платину (на ванильном камне), кусок —
  перекрашенный кусок гарниерита. Нормальные текстуры под породы TFC — dev #363.

## Файлы

- `kubejs/startup_scripts/tfc_plans/platinum_ore.js` — блок (без своей добычи, теги кирки/обвала/разведки) и предмет.
- `kubejs/server_scripts/tfc_plans/platinum_ore.js` — два рецепта дробления.
- `kubejs/data/kubejs/loot_table/blocks/ore/platinum.json` — добыча.
- `kubejs/data/tfc_plans/worldgen/…/vein/platinum.json` — жила `tfc:cluster_vein` и её размещение.
- `kubejs/data/tfc/tags/worldgen/placed_feature/in_biome/veins.json` — **заменяет** файл сборки: в нём был только
  `rocketnautics:vein/titanium`, теперь он и платина. Новые жилы в `kubejs/data` дописывать сюда же.
- `kubejs/assets/kubejs/textures/{block,item}/ore/…` — временные текстуры.

Почему накладка, а не карточка датапака сайта: жила ссылается на блок из стартового скрипта. Датапак, поставленный
без скрипта, ломает загрузку мира, поэтому всё идёт одним обновлением.

## Установка хостом

```bash
npm run tfc -- admin propose pack-patches/platinum-ore --note "Платиновая руда (сперрилит): редкие жилы в габбро, дробление в пыли платины, палладия и родия (dev #362)" --yes
```

Хост забирает обновление (`tfc admin updates pull <id>`), перезапускает сервер и клиент, проверяет блок и кусок в
JEI/EMI, рецепты дробления, затем `tfc admin updates approve <id>`. Жилы появятся только в **новых** чанках.
Откат: убрать файлы накладки, вернуть `in_biome/veins.json` к одному титану и перезапустить сервер.
