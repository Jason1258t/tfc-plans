# Исправление загрузки жил Create Ore Excavation

Dev-задача [#136](https://tfc-plans-fd2c.web.app/dev?task=136). Накладка заменяет
`kubejs/server_scripts/recipes/create/create.js` из снимка `20261029-084802-0246`.

## Причина и исправление

В Create Ore Excavation 1.6.8 помощник KubeJS `vein` записывает `name` через
`ComponentSerialization.CODEC`: перевод становится объектом. Загрузчик `VeinRecipe.Serializer`
читает это же поле через `ComponentSerialization.FLAT_CODEC`, которому нужна строка с JSON внутри.
Рецепт отклоняется с ошибкой `Not a string`; после удаления штатных жил сборке нечего показывать
в командах `/coe`, атласе и поиске.

Все 27 собственных жил теперь создаются через `event.custom` с `name: JSON.stringify(...)`.
Сохранены ID `create:vein/*`, ключи переводов и запасные названия, иконки, соль, интервалы,
ограничения Нижнего мира, конечность и множители запасов. 27 рецептов бурения, их добыча и время
сохранены. Остальные рецепты исходного файла сохранены; форматирование приведено к Prettier.

## Проверки

- Через MCP прочитаны кодеки мода, помощники KubeJS и актуальный скрипт снимка сборки.
- Одноразовое выполнение исходного и исправленного разделов скрипта: 27 жил и 27 рецептов бурения
  совпадают по всем значениям после приведения названия к требуемой строке; 54 уникальных ID.
- Отдельный сервер NeoForge 21.1.251, Create 6.0.10, COE 1.6.8, KubeJS 2101.7.2-build.368:
  старый вызов помощника воспроизводит ошибку `Not a string`; исправленные уголь, древние обломки
  и кварц загружаются. `/coe setvein 0 64 0 create:vein/coal` и `/coe locate create:vein/coal`
  выполняются успешно.
- `npm run lint` — без ошибок (имеющиеся предупреждения сайта); Prettier.

Серверная проверка выполнена на сокращённом стенде с тремя жилами, без полного скрипта сборки.
Полный набор из 27 жил проверен сравнением данных. В игре не проверялось: автодополнение на клиенте,
отображение атласа/поисковика, реальное бурение и существующие месторождения мира.

## Установка и откат

```bash
npm run tfc -- admin propose pack-patches/coe-vein-ids --note "Dev #136: исправлен формат названий 27 жил COE; прежние ID, генерация и бурение сохранены" --yes
```

Выложено обновление **`u20261029-091146-275f`** к снимку `20261029-084802-0246`.

Хосту: забрать предложенное обновление через `tfc admin updates pull u20261029-091146-275f`, перезапустить сервер,
проверить отсутствие ошибок `create:vein/*` в журнале KubeJS, подсказки
`/coe setvein ~ ~ ~ `, атлас, поиск и бурение. Для ручной проверки ID угля — `create:vein/coal`.
Затем одобрить через `tfc admin updates approve u20261029-091146-275f`.

Откат: восстановить `create.js` из указанного исходного снимка и перезапустить сервер.
Не удалять весь файл: в нём также находятся остальные рецепты Create сборки.
Публикация — штатным процессом сервера сборки после одобрения хостом; деплой сайта не требуется.
